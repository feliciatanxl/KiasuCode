### 🚀 OVERVIEW

KiasuCode is a production-grade Telegram bot architected to streamline academic performance tracking and project management for students in Singapore. Version 3.0, the **Enterprise Build**, introduces a robust **CI/CD Pipeline Monitor** alongside its core branching architecture.

Developed with a "Senior Dev" persona, the bot uses a hybrid of Singlish and developer jargon to guide users through their academic deployment cycle. It treats every module as a repository commit and every deadline as a critical pipeline issue, ensuring no "merge conflicts" in your graduation schedule.

---

### 🏛️ TECHNICAL IMPLEMENTATION DETAILS

* **Surgical ID-Based Operations:** To prevent collisions with duplicate task names (e.g., multiple "ICA1" entries), the system utilizes a **Primary Key targeting strategy**. Users perform destructive actions (dropping/patching) using unique **Issue IDs** generated by the MySQL backend.
* **Automated GPA Synchronization:** The database layer implements a post-insertion trigger logic. Every time a new module is committed, the system automatically invokes `updateStudentGPA` to recalculate and sync the user's CGPA "Source of Truth" instantly.
* **Staging vs. Production Isolation:** A dual-table strategy separates real grades (`module_grades`) from simulation data (`module_components`). This ensures "agak-agak" forecasts never pollute permanent academic records.
* **Enterprise Pipeline Health Checks:** Integrated with `node-cron`, the bot performs automated scans for upcoming deadlines. It broadcasts critical warnings for issues due within 72 hours, acting as a real-time monitor for academic blockers.
* **SGT Timezone Synchronization:** All logs, pipeline reports, and automated warnings are locked to **Singapore Standard Time (SGT)** using the `Intl.DateTimeFormat` API.

### 🎯 KEY FEATURES

* 📋 **Pipeline Monitor (**`/pipeline`**):** A centralized dashboard for all active project issues. Includes urgency color-coding (🟢, 🟡, 🔴) and real-time "Overdue" status logic.
* 🎯 **Surgical Issue Ops (**`/drop_issue`**):** High-precision task management. Resolve or delete specific pipeline issues using their unique numeric ID to avoid accidental multi-row deletion.
* 🧪 **Staging Engine (**`/agak_agak`**):** A simulation sandbox for component-level forecasting. Calculate exactly what score you need for that final project to maintain your build status.
* 📈 **Chiong Projection Engine (**`/chiong`**):** Dynamic "Error Budget" calculator. Know your safety margin and how many B's or C's you can afford while staying on track for your target CGPA.
* 🛠️ **Smart Hotfixes (**`/patch`**):** Interactive routers for both academic modules and pipeline deadlines. Reschedule tasks or edit grade values via a premium inline keyboard interface.
* 💊 **Copium Simulator (**`/copium`**):** High-velocity motivation injection for when the academic build feels like it's failing.

### 📁 PROJECT\_STRUCTURE

* `src/index.ts`: Main entry point; handles database pooling, global error catching, and command registration.

* `src/commands/pipeline.ts`: Dashboard logic for the enterprise issue tracker.

### 🛠️ COMMAND REFERENCE

**Production & Pipeline Ops**

* `/checkout <SCH> <YR> <SEM>`: Switch the active branch.
* `/commit <CODE> <CR> <GR> <NAME>`: Deploy a new grade with automated GPA sync.
* `/pipeline`: View all active issues and their **Issue IDs**.
* `/deadline <TASK> <DATE>`: Open a new critical pipeline issue.
* `/drop_issue <ID>`: Surgical removal of a task by its ID.
* `/patch`: Open the Smart Hotfix menu (GUI).

**Staging & Dev Tools**

* `/agak_agak <MOD> <NAME> <SCORE> <WT%>`: Forecast targets in staging.
* `/chiong <CR_LEFT> <TARGET>`: Calculate your safety margin budget.
* `/lobang`: Pull the Developer Manual (Help).
